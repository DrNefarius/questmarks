# Deliver: Kamihr Drifts

The game knows this assignment as: Deliver: Kamihr Drifts   (quest/coalition #25)

## Giver
Task Delegator - Western Adoulin (G-7)
  (resolved from the Couriers' Coalition page; the assignment page names no NPC)

## Couriers Assignment Table

Rank:        Legend

Objective:   Bring supplies from the Frontier Station in Kamihr Drifts back to the assignment desk.
IMP1:        4500
IMP2:        8100

## Walkthrough
[1] Once you accept the assignment, you will -not- be provided with any supplies. You will receive Kam. FS resource container at the Frontier Station.
    - As of Feb 18, 2014 update, Waypoints and Warp spell can be used to complete this task. Kam. FS resource container will not break.
[2] Speak to the Station Administrator to receive Kam. FS resource container.
[3] Return to the Task Delegator to deliver the supplies and receive your reward.

## After the walkthrough: Notes
[1] Movement speed increasing effects recommended.
