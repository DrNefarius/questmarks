## Walkthrough

[1] Speak to Omer to begin this quest.
[2] The item Omer asks for drops off Krakens fished up in Qufim Island.
    - No fishing skill is required to pull this up.
[3] Return the fishing rod to Omer for your reward.

[4] The game will freeze on the cutscene if you have your FPS set to 60. To set it to 30 with Windower use //config FrameRateDivisor 2
