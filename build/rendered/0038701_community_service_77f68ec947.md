## Walkthrough

[1] Note: This quest is only offered to one player per Vana'diel Day, per World.
[2] Speak to Zauko in Lower Jeuno at (I-6) between 18:03 and 21:00.
[3] You must light all of the Streetlamps in Lower Jeuno before 01:00.
    - To light one, simply run up to it and interact with it.
    - There are 12 total that must be lit.
    - You only need to light all 12 before 1:00. You can return to Zauko after that for credit.
[4] Repeating this quest a second time grants the Lamp lighter's membership card. This item functions similar to the Marble Bridge coaster. You receive a notification when you zone into Lower Jeuno if Zauko is looking for assistance.

If nobody accepts Zauko's quest before 1:00 game time, Vhana Ehgaklywha can be seen lighting the streetlamps.
