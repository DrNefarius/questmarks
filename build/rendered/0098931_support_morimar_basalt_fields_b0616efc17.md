# Support: Morimar Basalt Fields

The game knows this assignment as: Support: Morimar Basalt Fields   (quest/coalition #28)

## Giver
Task Delegator - Western Adoulin (G-7)
  (resolved from the Couriers' Coalition page; the assignment page names no NPC)

## Couriers Assignment Table
Coalition:   Couriers' Coalition
Rank:        Disciple
Type:        Frontline Support
Zone:        Morimar Basalt Fields
Objective:   Bring supplies to a frontier bivouac in Morimar Basalt Fields.
IMP1:        1500
IMP2:        2700
IMP3:        3600

## Walkthrough
[1] Upon accept this assignment, the Task Delegator will provide you with a Mor. FB op. materials container to deliver to any frontline bivouac in Morimar Basalt Fields.
    - As of Feb 18, 2014 update, Waypoints can now be used to complete this task. Mor. FB op. materials container will not break.
    - If you cancel the task, you will have your Imprimatur(s) refunded. No Imprimatur(s) are lost.
    - Using the Black Magic spell Warp does not seem to break the Mor. FB op. materials container.

[2] Bring the Mor. FB op. materials container to any Bivouac Administrator in the designated area(s) to complete the assignment.
    - Bivouac Administrator #1: (J-8)
    - Return to Bivouac Administrator #2: (I-6) for a reward of 2500 EXP./Bayld.
    - Bivouac Administrator #3: (I-10)
    - Return to Bivouac Administrator #4: (F-8)  for a reward of 3000 EXP./Bayld.
    - Return to Bivouac Administrator #5: (G-6) (higher level, past the F-6 Reive)  for a reward of 3500 EXP./Bayld.

## After the walkthrough: Notes
[1] Due to variable rock blockages, the same route used to go to a certain bivouac may not be available constantly.
[2] Same rewards were given when turning it into an already built bivouac.
[3] It is advised to turn in at an unbuilt bivouac if possible to help speed up the colonization rate of the area by allowing the bivouac to be built once enough supplies are delivered.
[4] Attempting to turn it in to a Bivouac Administrator with the key item broken will result in the message: "I'm terribly sorry, but we can't use broken containers of Morimar frontier bivouac operations materials."
[5] The Beastmaster and Ranger ability Wide Scan can pick up Bivouac Administrators.
