## Walkthrough

[1] Speak to Magephaud in Norg (I-8) to begin the quest.
    - You must have defeated a Tonberry before being able to start this quest.
[2] Trade him 3 Gold Beastcoins to receive the [KI] Tonberry key (Zilart).

== Tonberry Hate Reset: ==

The reward [KI] Tonberry key (Zilart) allows accessing the Tonberry Priest to reset Tonberry Hate in exchange for a gil penance at any time.

This can range between 250 - 6,000 gil depending on how much you have accumulated.

The Tonberry Priest is located in the Temple of Uggalepih at (F-11) on Map 1 behind a blank targetable secret door. Fastest route is via the Survival Guide or Voidwatch Warp and heading south.

Caution: There is also a [KI] Tonberry key (Shantotto) from A Shantotto Ascension Missions, which is a temporary key item. Everyone's Grudge rewards the permanent key item.

If you are having issues resetting Tonberry Hate via this quest, then it is very possible you have the wrong key item.
[3] Check with Magephaud in Norg to see if he requests the 3 Gold Beastcoins to be sure.
[4] If Magephaud requests the beastcoins, then you should receive the [KI] Tonberry key (Zilart) to reset hate after providing the 3 Gold Beastcoins to him.
