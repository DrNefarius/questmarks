# Provide: Kamihr Drifts

The game knows this assignment as: Provide: Kamihr Drifts   (quest/coalition #20)

## Giver
Task Delegator - Western Adoulin (G-7)
  (resolved from the Couriers' Coalition page; the assignment page names no NPC)

## Couriers Assignment Table
Coalition:   Couriers' Coalition
Rank:        Magnate
Type:        Base Provisions
Zone:        Kamihr Drifts
Objective:   Transport provisions to the site in Kamihr Drifts where the frontier station is to be constructed.
IMP1:        3500
IMP2:        6300
IMP3:        8400

## Walkthrough
[1] Once you accept the assignment, the Task Delegator will provide you with a Kam. FS building mat. container to deliver to a Station Administrator in Kamihr Drifts.
    - DO NOT use a Waypoint warp. Doing so will cause the Kam. FS building mat. container to break and make you unable to complete the assignment.
        - As of the [http://forum.square-enix.com/ffxi/threads/40059-Feb-18-2014-%28JST%29-Version-Update?p=493165&viewfull=1#post493165 Feb. 18 2014 Version Update], Waypoints can now be used to complete this task without risk of break. Simply warp to a Station Administrator.
[2] Head to Kamihr Drifts and speak to the Station Administrator to complete the assignment.
[3] Return to the Task Delegator to receive your reward (you may use Waypoints again now).
